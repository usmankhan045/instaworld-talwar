# GitHub Actions Integration

## Overview

This repository uses **GitHub Actions** to handle the InstaWorld sync cron job, running every **15 minutes** to keep your Shopify app synchronized with InstaWorld booking data.

## Architecture

**Core Components:**
- **GitHub Actions Workflow** (`.github/workflows/cron-sync.yml`) - Triggers every 15 minutes, calls `/api/instaworld-sync`
- **Enhanced API Route** (`app/routes/api.instaworld-sync.ts`) - Supports both Vercel and GitHub Actions authentication
- **Repository Secrets** - API keys and authentication tokens

## Key Benefits

✅ **Zero Infrastructure Costs** - No Vercel Pro upgrade needed
✅ **Unlimited Cron Frequency** - Every 15 minutes for free
✅ **Enhanced Monitoring** - Detailed logging and error handling
✅ **Flexible Authentication** - Supports both Vercel and GitHub Actions
✅ **Production Ready** - Comprehensive error handling and health monitoring
